# BMI Calculator

## Objective
The objective of this project is to develop a simple BMI Calculator that calculates Body Mass Index (BMI) based on the user's height and weight and determines the corresponding BMI category.

## Project Description
This BMI Calculator allows users to enter their weight and height and calculates their BMI using the standard BMI formula. The calculated BMI is then classified into the appropriate category.

## Formula
BMI = Weight (kg) / Height² (m²)

## BMI Categories
- Underweight: BMI below 18.5
- Normal weight: BMI 18.5 – 24.9
- Overweight: BMI 25 – 29.9
- Obese: BMI 30 or above

## Technologies Used
- Python
- Basic Mathematical Operations
- Conditional Statements
- User Input and Output

## Steps Performed
1. Took weight as input from the user.
2. Took height as input from the user.
3. Converted the required values into appropriate units.
4. Calculated BMI using the standard formula.
5. Used conditional statements to determine the BMI category.
6. Displayed the calculated BMI and category.

## Outcome
Successfully developed a functional BMI Calculator that calculates BMI and displays the corresponding BMI category based on user input.

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file.
5. Enter your height and weight when prompted.
